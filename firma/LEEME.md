# Llave de firma de PRUEBA (debug)

`debug.keystore` es una llave de **depuración** compartida (contraseña `android`, alias `androiddebugkey`).
Con ella firman el APK tanto Android Studio en el PC como GitHub Actions, así que se puede instalar
uno encima del otro sin desinstalar ni perder datos.

No es secreta ni sirve para publicar en Play Store: para eso se usaría otra llave, guardada aparte.
